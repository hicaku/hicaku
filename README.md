# Hi, I'm Hikmet 👋

**Software engineer · Frontend / Full-Stack**, based in Malta. 8+ years of building web apps end to end, from a global
map product at Huawei (20M+ monthly users) to AI-powered CRM platforms. I work in Vue, React, TypeScript and Go, and I
care about performance, reliability and well-tested code.

- 💻 Software Engineer at **Fast Track** (Malta) since February 2024
- 🗺️ Before that: Huawei (Petal Maps), GoArt Metaverse, and my first jobs at Firmasoft and Datapare in Istanbul
- 🎓 B.Sc. Mathematics Engineering, Istanbul Technical University

<br/>

## 🌐 My website is a game

**[hicaku.dev](https://hicaku.dev)** is a neon 3D portfolio. You run through Istanbul, take the ferry across the Bosphorus,
fly to Malta, drive a Red Bull-style F1 car, and unlock a world tour of the places I've been to. Every landmark tells its
history, it's available in six languages, and my CV is one click away.

Built with Vue 3, TypeScript, Vite and three.js with hand-written shaders. Everything in the world is generated in code.
**[Source code →](https://github.com/hicaku/hicaku-portfolio)**
